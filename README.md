# Custom sounds — мод для Geometry Dash (Geode)

Заменяй любой звук в игре своим файлом.

## Как пользоваться
1. В главном меню нажми зелёную кнопку внизу (в нижнем меню).
2. Найди звук в списке (есть поиск), кнопка ▶ проигрывает его.
3. Нажми **Replace** и выбери свой `.mp3`, `.ogg` или `.wav`.
4. Крестик справа возвращает оригинальный звук. Заменённые звуки подсвечены зелёным.

Файлы копируются в папку сохранений мода, поэтому исходник можно перемещать или удалять.

## Как получить файл .geode
Самый простой способ — GitHub Actions:
1. Создай репозиторий на GitHub и залей туда содержимое этой папки.
2. Открой вкладку **Actions** → workflow **Build Mod** (запустится сам при push).
3. Когда сборка закончится, скачай артефакт **Build Output**: внутри будет `semen0502psa.custom-sounds.geode`.
4. Положи файл в папку `geode/mods` игры (или установи через кнопку в меню модов Geode).

## Локальная сборка
Нужны Geode CLI и SDK (`GEODE_SDK`), затем: `geode build`.
